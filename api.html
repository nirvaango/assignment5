All the Music You'll Ever Need to Know About

The API I selected, and why

  • The API I selected is the iTunes Search API
  • The iTunes Search API lets anyone search the iTunes Store Catalog
  • It returns songs, albums, movies, podcasts, etc
  • For each query, the API returns the title, artist, album, genre, release date, price, album artwork, and a link to a 30-sec audio preview
  • I chose this API because it matched all the requirements, but also because it returns rich data like album artwork and a 30-second audio preview, which let me build something more interactive than just plain text.

The website where I found it

  • I specifically looked for Music-based keyless APIs that return data in a JSON format
  • While doing so, I came across this list.
  • That led me to the API's source docs from Apple

Options/Parameters used for API request

  • The API is called with a GET request to https://itunes.apple.com/search, with 3 parameters in the query string:
    • term: the search query, coming from what the user types in the search box. This is URL-encoded with encodeURIComponent() so names with special characters don't break the URL.
    • media=music: limits results to music only. Without it, the API also returns movies, podcasts, apps, and books.
    • limit=6: caps the number of results at 6. The default is 50.

An example where this API would be helpful

  • This API could be quite useful if one were to build a music cataloguing app like Letterboxd, but for songs instead of movies.
